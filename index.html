YouTube Chat Arcade

The stream where the chat plays the game.

What is it?

Welcome to the YouTube Chat Arcade! This stream is entirely controlled by you and the rest of the chat. There is no host—just the audience working together (or against each other) to beat classic games directly on the live stream.

You interact by typing specific commands starting with an exclamation mark ! directly into the YouTube live chat.

How It Works

To prevent absolute chaos, the arcade engine processes commands using a 1-Second Action Window.

The Golden Rule:

During a game of Tetris or Sokoban, the engine waits 1 second between moves. The VERY FIRST valid command typed in chat during that window is the one that gets executed. If you're too slow, your command is ignored until the next window!

To start playing or switch games, anyone can type a global game command. If you want to stop a game, type !game quit (requires half the chat to agree via voting).

The Games & Commands

🎮 Main Menu

When the arcade is idle, type these to launch a game:

  • !game ttt (Tic-Tac-Toe)
  • !game tetris (Tetris)
  • !game sokoban (Sokoban)

❌ Tic-Tac-Toe

A classic 1v1 game. Join the queue and fight for victory! The UI clearly shows who is playing X and O. When someone wins, the game pauses for 3 seconds so the victor can bask in glory before returning to the main menu and declaring the winner in the global chat!

  • !ttt join (Join game)
  • !ttt top left (Play top left)
  • !ttt center (Play center)
  • !ttt bottom right

🧱 Tetris

Survive as long as you can on a wider 14x15 board! The right-side panel tracks exactly which user made the last successful move. Plus, a strict gravity timer forces the piece down every 10 seconds unconditionally, so the game never stalls!

  • !left or !l
  • !right or !r
  • !rotate or !up
  • !drop or !down

📦 Sokoban (Detailed Guide)

Sokoban is a classic puzzle game where you play as a warehouse worker pushing crates to designated storage locations. The Arcade generates procedurally infinite, clean maps (only 2% obstacle density and exactly 1-3 crates), making puzzles perfectly manageable. It features a minimalist UI that displays the latest player's username!

The Symbols

  • ☻ You (The Player)
  • □ Crate (To be pushed)
  • · Goal (Storage spot)
  • █ Wall (Impassable)
  • ▣ Crate safely on a Goal!

The Rules

  • You can only push one crate at a time.
  • You cannot pull crates.
  • If you push a crate into a corner, it's stuck forever!
  • Work with chat to avoid soft-locking the puzzle!

Commands:

  • !up or !u
  • !down or !d
  • !left or !l
  • !right or !r
  • !reset (Restarts if you get stuck)
