What is it?

Welcome to the YouTube Chat Arcade! This stream is entirely controlled by you and the rest of the chat. There is no host—just the audience working together (or against each other) to beat classic games directly on the live stream.

You interact by typing specific commands starting with an exclamation mark ! directly into the YouTube live chat.

How It Works

To prevent absolute chaos, the arcade engine processes commands using a 1-Second Action Window.

The Golden Rule: During a game of Tetris or Sokoban, the engine waits 1 second between moves. The VERY FIRST valid command typed in chat during that window is the one that gets executed. If you're too slow, your command is ignored until the next window!

To start playing or switch games, anyone can type a global game command. If you want to stop a game, type (requires half the chat to agree via voting).

Sokoban

Sokoban is a classic puzzle game where you play as a warehouse worker pushing crates to designated storage locations. The Arcade generates procedurally infinite, clean maps (only 2% obstacle density and exactly 1-3 crates), making puzzles perfectly manageable. It features a minimalist UI that displays the latest player's username!

The Symbols

  • ☻You (The Player)
  • □Crate (To be pushed)
  • ·Goal (Storage spot)
  • █Wall (Impassable)
  • ▣Crate safely on a Goal!

The Rules

  • You can only push one crate at a time.
  • You cannot pull crates.
  • If you push a crate into a corner, it's stuck forever!
  • Work with chat to avoid soft-locking the puzzle!
